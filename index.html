Що таке Python?

Python — одна з найпопулярніших мов програмування: проста для читання, але потужна. Нею створюють сайти, ігри, аналіз даних, штучний інтелект і автоматизацію. На цьому сайті ти можеш писати й запускати Python прямо в браузері — без встановлення чогось додаткового.

Для чого цей проєкт?

Це навчальний майданчик: знайомся з Python на готових прикладах, тренуйся з підказками, відпочивай у міні-іграх та інструментах, зберігай рекорди у профілі. Усе працює локально в браузері (демо, без сервера), тож усі дані залишаються у тебе.

З чого почати?

Відкрий Python-майданчик, обери приклад «Привіт, світ» і натисни «Запуск». Потім спробуй підказки рівнів 1–3: змінні, умови, цикли. Коли набридне код — грай у ігри або перевіряй інструменти.
